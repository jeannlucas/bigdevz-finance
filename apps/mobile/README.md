# BigDev.Z Finance — app Flutter

Aplicativo iOS/Android que consome exclusivamente a API Laravel em `apps/api`.
Comandos, endereços da API por dispositivo e estado de validação estão no
`README.md` da raiz. Estrutura por funcionalidade em `lib/features/`; dinheiro
como centavos inteiros em `lib/core/money.dart` (sem `double`).
